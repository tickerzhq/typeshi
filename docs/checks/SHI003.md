# SHI003: an unchecked account nothing checks

`UncheckedAccount` and `AccountInfo` are accounts Anchor checks nothing about: not who owns
them, not what data they hold, not their address. Anchor asks for a `/// CHECK:` comment
above them, and a comment checks nothing. Any account fits, including one the attacker
made, filled with whatever data makes the program do what they want.

typeshi refuses a raw account unless something pins it: `address = ...` (the one account it
may be), `owner = ...` (the program that must own it), `seeds = [...]` (a PDA this program
derives) or a `constraint`.

## Example

```shi,fail
gm!("7PxhmDuhhe394QJgKyW1P7Ce4dPCfFPN2yKq4KCCj7Vj");

stealth_launch bridge {
    cap_table Verify {
        /// CHECK: the instructions sysvar
        instructions: UncheckedAccount,
        anon,
    }

    ape fn verify(ctx) -> W {
        let data = ctx.accounts.instructions.try_borrow_data()?;
        trust_me_bro!(data.len() > 0, "no instructions to verify");
        were_so_back!()
    }
}
```

The program reads "the instructions sysvar", but nothing says it is. An attacker passes an
account of their own with instructions that were never signed.

## Fix

Pin it to the one account it may be:

```shi,pass
gm!("7PxhmDuhhe394QJgKyW1P7Ce4dPCfFPN2yKq4KCCj7Vj");

stealth_launch bridge {
    cap_table Verify {
        /// CHECK: pinned to the instructions sysvar
        #[account(address = anchor_lang::solana_program::sysvar::instructions::ID)]
        instructions: UncheckedAccount,
        anon,
    }

    ape fn verify(ctx) -> W {
        let data = ctx.accounts.instructions.try_borrow_data()?;
        trust_me_bro!(data.len() > 0, "no instructions to verify");
        were_so_back!()
    }
}
```

Better still, give it a type Anchor checks: `Account<T>` for your own data, `Sysvar<T>` for
a sysvar, `Program<T>` for a program.

## What it has cost

- **Wormhole, 2022-02-02: 120,000 wETH minted, about $320M.** `verify_signatures` read the
  instructions sysvar through an account it never checked, so the attacker passed their own
  and minted wrapped ETH with no ETH behind it
  ([Kudelski Security's analysis](https://kudelskisecurity.com/research/quick-analysis-of-the-wormhole-attack)).
- **Crema Finance, 2022-07-02: about $8.8M.** A fake tick account passed the owner check
  ([CoinDesk](https://www.coindesk.com/tech/2022/07/04/solana-defi-protocol-crema-loses-88m-in-exploit)).

## What it doesn't catch

A `constraint` counts as a check even if it checks the wrong thing, and `owner = X` trusts
whatever program X is. typeshi also can't see accounts a program reads from
`remaining_accounts`.
