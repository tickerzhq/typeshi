# SHI004: a program to call that can be any program

When a program calls another one (a CPI), it trusts what that program does and what it
returns. `Program<Token>` makes Anchor check the address is the Token program. A bare
`Program`, or an unchecked account named as a program, accepts any executable account, so an
attacker passes a program they wrote that returns whatever they like.

typeshi refuses a program account that isn't named or pinned.

## Example

```shi,fail
gm!("7PxhmDuhhe394QJgKyW1P7Ce4dPCfFPN2yKq4KCCj7Vj");

stealth_launch lender {
    cap_table Quote {
        /// CHECK: the rate program
        rate_program: UncheckedAccount,
        anon,
    }

    ape fn quote(ctx) -> W {
        let rate_id = ctx.accounts.rate_program.key();
        probably_nothing!("asking {} for a price", rate_id);
        were_so_back!()
    }
}
```

## Fix

Pin it to the program it must be:

```shi,pass
gm!("7PxhmDuhhe394QJgKyW1P7Ce4dPCfFPN2yKq4KCCj7Vj");

stealth_launch lender {
    deadass RATE_PROGRAM: Pubkey = pubkey!("Fg6PaFpoGXkYsidMpWTK6W2BeZ7FEfcYkg476zPFsLnS");

    cap_table Quote {
        /// CHECK: pinned to the rate program
        #[account(address = RATE_PROGRAM)]
        rate_program: UncheckedAccount,
        anon,
    }

    ape fn quote(ctx) -> W {
        let rate_id = ctx.accounts.rate_program.key();
        probably_nothing!("asking {} for a price", rate_id);
        were_so_back!()
    }
}
```

For a program Anchor knows, name it instead: `Program<Token>`, `Program<System>`.

## What it has cost

- **Loopscale, 2025-04-26: about $5.8M (later recovered).** The program ids of the RateX
  programs it priced collateral with were not validated on one path, so a spoofed program
  returned an inflated price
  ([Loopscale's post-mortem](https://blog.loopscale.com/posts/postmortem)).

## What it doesn't catch

A program id that arrives as an instruction argument, or a call made with `invoke` on an id
read from account data. Pin those with a constant too.
